# Extension Icons

Please create the following icon files in this directory:

1. `icon16.png` - 16x16 pixels
2. `icon48.png` - 48x48 pixels
3. `icon128.png` - 128x128 pixels

You can use any image editing software to create these icons. For a quick solution, you can convert any visa or passport related image to these sizes.

Recommended tools:
- Adobe Photoshop
- GIMP (free)
- Online icon generators

For a quick placeholder, you can use a simple colored square with a "V" letter for "Visa".
